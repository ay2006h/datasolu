# DataSolu - منصة تحليل بيانات الأعمال الذكية (Smart Business Analytics Platform)

منصة تفاعلية حديثة ومتكاملة لتحليل بيانات الأعمال من شيتات الإكسيل (`.xlsx`, `.xls`, `.csv`)، وتصميم رسوم بيانية توضح موقف الأعمال ومؤشرات الأداء بدقة واحترافية، مع دعم كامل للغتين **العربية (RTL)** و**الإنجليزية (LTR)**.

---

## ✨ الميزات الرئيسية (Features)

1. **تحليل ذكي لملفات الإكسيل**:
   - التعرف الآلي على أنواع الأعمدة (تواريخ، أرقام ومبالغ مالية، حالات تشغيلية، فئات وأقسام).
   - دعم ملفات متعددة الأوراق (Multi-sheet workbooks) مع إمكانية التبديل بين أوراق العمل فوراً.

2. **رسم بياني ومؤشر يوضح موقف الأعمال (Business Status & Executive Health Score)**:
   - مؤشر دائري تفاعلي يقيس درجة صحة وكفاءة الأعمال (Health Score Index).
   - توزيع حالات العمليات (مكتمل / قيد التنفيذ / معلق / متأخر).
   - مقارنة الإنجاز الفعلي مقابل المستهدف المخطط.

3. **لوحة تحكم تنفيذية ورسوم بيانية متنوعة (Executive Charts)**:
   - رسم خطي/مساحي لتتبع الاتجاهات عبر الزمن (Trends over Time).
   - رسم أعمدة لمقارنة الأداء بين الفروع والأقسام (Category Breakdown).
   - رسم دائري/حلقي يوضح الحصص النسبية والتوزيع (Market Share & Distribution).
   - مصفوفة رادار لمقارنة توازن مؤشرات الأداء (Performance Radar).

4. **منشئ رسوم بيانية مخصص (Custom Chart Builder)**:
   - يتيح لك اختيار أي عمود للمحور الأفقي والرأسي واختيار نوع الرسم وطريقة التجميع (مجموع، متوسط، عدد، حد أقصى، حد أدنى) والترتيب الفوري.

5. **توليد رؤى وتوصيات الأعمال الذكية (Smart Automated Insights)**:
   - ملخص تحليلي تلقائي يحدد أعلى الفئات مساهمة في الأرباح، التنبيهات التشغيلية عند وجود تأخيرات، وفرص التطوير.

6. **جدول محوري تفاعلي (Pivot Table)**:
   - تجميع وتحليل البيانات ومقارنة الأرقام وفق بعدين في وقت واحد مع حساب الإجماليات الفرعية والعامة.

7. **مستعرض بيانات تفصيلي (Data Table Viewer)**:
   - بحث شامل فوري، فرز الأعمدة تصاعدياً وتنازلياً، فلاتر مخصصة، وتصدير البيانات بصيغة CSV تدعم اللغة العربية (UTF-8 BOM).

8. **تصدير التقارير (PDF Export)**:
   - تصدير لوحة المؤشرات والرسوم البيانية كتقرير تنفيذي بصيغة PDF عالي الجودة بنقرة واحدة.

## 🚀 كيفية التشغيل (How to Run)

### الطريقة الأولى: بنقرة واحدة (One-Click)
اضغط مرتين على ملف:
```text
start.bat
```

### الطريقة الثانية: عبر سطر الأوامر (Terminal)
```bash
# 1. التثبيت (تم مسبقاً)
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على الرابط:
👉 **`http://localhost:5173`**
